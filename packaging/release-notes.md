## Install

**macOS** — with [Homebrew](https://brew.sh):

```
brew install --cask akshatgg/tap/souffleur
```

Installs and opens with nothing to click through. The `.dmg` below works too, but the build is not notarised, so a manually downloaded copy is refused until you approve it in System Settings → Privacy & Security → **Open Anyway**.

**Windows** — run the `.exe`. SmartScreen warns once: **More info → Run anyway**.

Then grant **Screen Recording** on macOS, or the overlay cannot see your screen or hear the call.
